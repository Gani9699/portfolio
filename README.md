# Personal Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript (no frameworks).

## Features

- Semantic structure: `header`, `nav`, `main`, `section`, `footer`
- Sections: Hero, About, Skills, Projects (3 showcases), Contact
- Responsive at 375px (mobile), 768px (tablet) and 1280px+ (desktop)
- JavaScript interactions: mobile nav toggle, dark/light mode (remembered between visits), project filter
- Accessible basics: skip link, focus styles, ARIA labels, reduced-motion support

## Tech used

HTML5, CSS3 (custom properties, Flexbox, Grxid, media queries), vanilla JavaScript (ES5-compatible).

## Run locally

1. Clone the repo: `git clone https://github.com/Gani9699/portfolio.git`
2. Open the folder in VS Code and start the **Live Server** extension, or simply open `index.html` in a browser.
